## 🚀 Selected Work

### [CFDPython](https://github.com/vinaykumar007/CFDPython)

Numerical solutions of fundamental fluid-flow PDEs using Python and Jupyter, covering convection, diffusion, Burgers' equation, Laplace, Poisson, and 2D Navier–Stokes problems.

**Focus:** numerical methods • PDEs • stability • convergence • scientific Python

### [PyReservoir](https://github.com/vinaykumar007/pyreservoir)

Python-based reservoir engineering utilities covering PVT analysis, volumetrics, well testing, material balance, decline-curve analysis, and fluid-flow calculations.

**Focus:** engineering computation • Python • modelling • data analysis

### [Computational Geophysics](https://github.com/vinaykumar007/computational-geophysics)

Python implementations of geophysical methods and workflows involving FFT-based analysis, seismic processing, inversion, geomodelling, and machine learning.

**Focus:** scientific computing • signal processing • inversion • geomodelling

### [GeostatsPy Intro Course](https://github.com/vinaykumar007/GeostatsPy_Intro_Course)

Python workflows for spatial/subsurface data analytics and geostatistics, including variogram analysis, variogram modelling, and kriging.

**Focus:** spatial statistics • geostatistics • Python • subsurface data
